# Crimson Nail
Crimson Nail is a card game project designed to
demonstrate and validate the capabilities of the ToyBox library.
This project structure and documentation are kept minimal,
unlike full-scale production C++ projects.

## Building
A compiler with C++20 support is strictly required.

### The Simplest Option
1. Download and install MinGW (TDM-GCC 10.3.0 is highly recommended for its lightweight ~600MB footprint and simple setup).
2. Download CMake (Version 3.15 or higher).
3. Build the project. (All 3rd-party libraries are pre-compiled with MinGW and included in the repository).

### The Formal Approach
This project can also be compiled using `Visual Studio 2022`.
However, you will need to manually manage the required dependencies and modify the CMakeLists.txt accordingly.

## Supported Platforms
* Current: Windows 7 or later.
* Planned: Linux support will be added in the future.
